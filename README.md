# 班委助手

面向班委的班级日常管理小系统，手机优先。技术栈：Vue3 + Vite + Vant4 + Pinia + SheetJS。
数据存浏览器本地（localStorage + IndexedDB），架构预留联机扩展。

## 开发

```bash
npm install
npm run dev
```

- 电脑访问 http://localhost:5173
- 手机连同一个 WiFi，访问终端里打印的 Network 地址，可直接在手机上试用

## 打包

```bash
npm run build   # 产物在 dist/，任意静态托管都能部署
```

## 部署（可选）

打包产物是纯静态文件，放到任意静态托管即可：

- **Vercel**：`npm i -g vercel && vercel`（需能访问国际网络）
- **腾讯云 EdgeOne Pages**：国内访问快，控制台导入或直接上传 dist
- **GitHub Pages**：推仓库后把 dist 内容放到 gh-pages 分支

部署后用手机打开网址，在浏览器菜单里"添加到主屏幕"，即可像 App 一样使用（PWA 离线可打开）。
注意：重新部署后把 `public/sw.js` 里的 `CACHE` 日期改一下，用户下次打开才会换新缓存。

## 联机同步（班委共享数据）

1. 注册 LeanCloud 免费账号并创建一个"开发版"应用：
   - 国际版 https://console.leancloud.app （国内可直连，无需实名/备案）
   - 国内版 https://console.leancloud.cn （需实名认证）
2. 进入应用 → 「设置」→「应用凭证」，拿到 **AppID / AppKey / API 访问地址**（三项都要）
3. 应用内「我的」→「联机同步」→ 填入并保存开启
4. 第一台设备点「上传数据」建立云端基准；其他班委设备打开同一网址 → 「下载数据」即可
5. 之后各设备增删改会自动同步（约 2 秒内推送），互相覆盖时以最后保存为准

说明：凭证图片暂不参与同步，只保存在记账人的设备上；数据含姓名学号，共享网址只发给班委。
部署后请在 LeanCloud 控制台配置「Web 安全域名」，详见 [SECURITY.md](./SECURITY.md)。

## 安全

- 支持**访问口令**（字母+数字，我的 → 访问口令），防止别人拿到手机后翻看班级数据；口令只存加盐哈希；
- 凭证上传有类型与大小校验，全部数据默认仅存本机；
- 生产构建注入 CSP 内容安全策略；SheetJS 使用官方修复版；
- 完整安全审计、边界与建议见 [SECURITY.md](./SECURITY.md)。
