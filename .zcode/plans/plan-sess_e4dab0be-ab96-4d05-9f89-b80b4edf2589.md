# v1.1.0 规划：工作台改版——两模块竖排直列（去标签页）+ 新建类型显式选择

## 一、新工作台布局（打开即见一切，零层级）

```
工作台
[速览横条：班费余额 | 进行中事务]（保留，纤细不占空间）

■ 待办 ────────────────────
  · 无 → 空状态"暂无待办"
  · 有 → 待办列表直接平铺（点击勾选完成、滑动删除）
  · 已完成 N ▾（折叠在模块底部，点击展开/收起）

■ 事务 ────────────────────
  · 无 → 空状态"暂无事务"
  · 有 → 事务卡片平铺：班级事务（负责人/进度条/截止）+ 个人事务（带"个人"标签，仅自己可见）
  · 已完成 N ▾（同上折叠）

右下角 + → 弹出选择面板：「新建待办 / 新建班级事务 / 新建个人事务」
```

- **取消全部三层标签页**，两个模块直接竖排平铺——点进页面第一眼就是"还有什么没做"；
- 每个模块**独立空状态**（没有就显示空，有你说的待办）；
- 新建类型从"跟随当前标签页"改为**弹面板显式选择**，从根上解决"添加了却不显示/建错位置"；
- 个人事务创建后立刻出现在事务模块（带"个人"标签），可见性规则不变（仅创建者可见）。

## 二、权限与规则（不变）

班长全权；班委可管理待办/事务（账目受限）；普通同学纯只读（无 + 号、无勾选、无滑动删除，只看）。

## 三、细节默认（可否决）

- 已完成项折叠显示（模块底部一行"已完成 N"，点击展开）；
- 速览横条保留在工作台顶部；
- 模块内排序：待办按日期（过期/今天在前），事务按截止时间（无日期在后）。

## 四、实施与验收

1. 重写工作台页：拆除三层标签，改为两模块平铺 + 折叠 + ActionSheet 新建面板（待办/班级事务/个人事务三种表单复用现有组件）；
2. 部署上线（带网络重试）；
3. 线上验收：空状态（清空测试数据后两模块显示空）、新建待办/班级事务/个人事务各一 → 三者立即出现在对应模块、勾选完成 → 折叠计数变化、普通同学视角只读、回收站联动删除恢复。
